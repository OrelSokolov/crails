Наблюдения:
- Наша машина даёт ~0.35–0.55× от upstream для компилируемых реализаций —
  ожидаемо для ноутбучных P-ядер против настольных Zen5.
- Rails-референс без whole-page кэша рендерит каждый ответ (Cache-Control
  private), поэтому отстаёт на два порядка, а не на один.
- Порядок display в search — документированная межреализационная разница
  (reference: по created_at; express/go/rust: по insertion id); контракт search
  для каждой реализации перестроен по её стабильному порядку, множество ID
  сверено с сид-SQL.
