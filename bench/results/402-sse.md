# 402 — SSE / chunked-стриминг (ActionController::Live)

Iteration 9: `ActionController::Live` 8.1.4 (порт `action_pack.cr/src/live.cr`)
против настоящего actionpack 8.1.4 + Puma 6.6.1 (thread mode, max_threads 256).
Клиент общий — `bench/crails_sse` (голые TCP-сокеты, подсчёт событий на лету);
Rails-контраг_pointка — `bench/rails_sse/server.rb` (те же эндпоинты).

Окружение: Linux, Crystal 1.21.0 (release), Ruby 3.4.5, loopback, один хост.

## Результаты

| Метрика | CRails (Live порт) | Rails 8.1.4 + Puma | Разрыв |
|---|---|---|---|
| SSE-fanout 50 конн. × 2000 «токенов» | 482–622k events/s | 31–41k events/s | **~15×** |
| Chunked-поток (35-байтные чанки) | 710–887k chunks/s (26–33 MB/s) | 115–117k chunks/s (4.3 MB/s) | **~6–7×** |
| First-token latency (200 конн., d=1мс) | avg 1.16 мс / p95 1.24 мс | avg 1.97 мс / p95 2.39 мс | ~1.7× |
| Disconnect-storm 200 конн. — отмена стримов | **120 мс** | **~6.05 с** | **~50×** |
| Disconnect-storm 200 — RSS сервера | 22.3 МБ | 74.7 МБ | ~3.3× |
| Disconnect-storm 1000 конн. (CRails) | 264 мс / RSS 57.7 МБ | — (не гоняли) | — |

SSE-фрейм: `data: token<i> \n\n` (~16 байт), «токены» без пауз —
худший случай для backpressure-буфера (queue_size 10). First-token:
сервер спит 1 мс перед первым токеном, меряется connect → первый байт
данных. Storm: клиенты читают ~200 байт вечного тика и рвут соединение;
отмена = все fiber'ы (CRails) / MRI-threads (Rails) экшена получили
ClientDisconnected и завершились.

## Интерпретация

- Backpressure работает симметрично: очередь из 10 чанк'ов держит RSS
  плоским при любом отставании клиента (storm 1000 → 58 МБ пик на
  1000 одновременных стримов, без роста до отмены).
- Отмена fiber'а при disconnect — главное архитектурное отличие:
  Puma+MRI перебирает 200 потоков ~6 с, CRails гасит 1000 fiber'ов
  за 264 мс. Для AI-стриминга (пользователь закрыл таб — LLM-стрим
  должен остановиться немедленно) это критичный слот таблицы
  «где обгоняем Next.js» из ECOSYSTEM.md.
- First-token 1.16 мс — цена fiber'а против пула потоков; в связке с
  solid-очередью даёт дешёвые долгоживущие SSE-соединения.
