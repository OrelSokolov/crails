# 000-hello — CRails vs Rails 8: `GET /` (Iteration 0)

Дата: 2026-10-02. План: `../../PLAN.md` (Iteration 0), `../PLAN.md` (000-hello).

## Окружение

- CPU: Intel Core Ultra 7 155H (22 потока), RAM 32 GB, ядро 6.19.14
- Клиент: wrk (4 threads), localhost, warmup перед замерами, по 3 прогона → медиана
- CRails 0.1.0 (Crystal 1.21.0, сборка `--release`, HTTP::Server, fiber-per-connection)
- Rails 8.1.1 (Ruby 3.4.5, Puma 8.0.2, `RAILS_ENV=production`, `RAILS_MAX_THREADS=16`, дефолтный middleware-стек `rails new --minimal`)
- Приложения: идентичная логика — `root "welcome#index"`, один контроллер,
  view + layout с одной инстанс-переменной
  (`hello_world/hello/`, `bench/rails_hello/`)

## Результаты

| Метрика | CRails | Rails 8 + Puma |
|---|---|---|
| RPS, c=10 (медиана 3 прогонов) | **141 802** | 233 |
| RPS, c=100 (медиана 3 прогонов) | **148 020** | 312 |
| Latency avg, c=10 | **73 µs** (max 5.4 ms) | 24 ms (max 103 ms) |
| Latency avg, c=100 | **~650 µs** (max ~7.7 ms) | ~262 ms |
| RSS после нагрузки | **~16 MB** | ~110 MB (старт ~88 MB) |
| Время старта (до первого 200) | **~10 ms** | ~950 ms |
| «Компиляция» | dev 2.1 s / release 20.4 s | bundle+boot ~1 s (/runtime) |
| Размер артефакта | 3.5 MB (бинарник) | интерпретируемый |

Полные прогоны CRails (RPS): c10 = 147.3k / 141.8k / 136.1k; c100 = 148.0k / 146.1k / 154.1k.
Rails: c10 = 272 / 233 / 220; c100 = 356 / 256 / 312.

## Вывод одной строкой

CRails отдаёт hello-world ~**600×** RPS Rails 8 (142k vs 233 при c=10) при
~**7×** меньшей памяти (16 vs 110 MB) и ~**95×** меньшем времени старта
(10 ms vs 950 ms); цена — 2–20 s компиляции на dev-цикл (закрывается `crails watch`).

## Примечания честности

- Rails в production-режиме с дефолтным стеком `rails new --minimal`
  (включая логирование в файл, HostAuthorization и пр.) — это то, что
  получает разработчик «из коробки»; тонкая настройка Rails (отключение
  логов, rack-tausb и т.п.) не проводилась — как и для CRails.
- p99 в явном виде не снят (wrk выводит перцентили строки распределения;
  зафиксированы avg/stdev/max) — при желании повторить: `make`-скрипта нет,
  команды в истории сессии.
- Числа ожидаемо экстремальны для обоих лагерей: Crystal HTTP::Server на
  статичном шаблоне против полного Rails middleware-стека; это верхняя
  граница «фреймворк-такси», а не типичная нагрузка. Ориентир для
  следующих итераций: как быстро разрыв сократится с появлением БД,
  сессий и AR.
